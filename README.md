# mis-skills

Mis skills para Claude Code, instalables en cualquier ordenador o sesión.

## Instalar (una sola vez por ordenador)

Dentro de Claude Code (terminal o pestaña Code de Claude Desktop):

```
/plugin marketplace add raulrubioaguilar-create/mis-skills
/plugin install mis-skills@mis-skills
/plugin install ponytail@mis-skills
```

## Actualizar

```
/plugin marketplace update mis-skills
```

## Añadir una skill nueva

- Skill suelta: carpeta `plugins/mis-skills/skills/<nombre>/SKILL.md`.
- Plugin externo de GitHub: nueva entrada en `.claude-plugin/marketplace.json`.

Nunca guardes contraseñas ni datos privados aquí: el repositorio es público.
